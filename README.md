# Місто подій

Навчальний ASP.NET Core MVC застосунок для каталогу локальних подій. Є CRUD для подій, місць і організаторів, JSON API, мапа з фільтрами, прогноз погоди та живі оновлення статусів. [Специфікація](SPEC.md), [етапи виконання](PROMPTS.md), [дизайн](DESIGN.md) і [короткий опис проєкту](PROJECT_BRIEF.md) зберігаються разом із кодом.

Публічний репозиторій: [Alemek1075/misto-podii](https://github.com/Alemek1075/misto-podii).

## Локальний запуск

Потрібен .NET SDK 8.0.425 або новіший патч у межах тієї самої SDK feature band. Команди виконувати з кореня репозиторію:

```powershell
dotnet restore
dotnet run --project src/MistoPodii
```

Адреса з'явиться у консолі. Міграції застосовуються під час запуску; SQLite-файл створюється локально й ігнорується Git. Два демонстраційні місця, організатори й події додаються у нову базу.

## API та перевірки

| Ресурс | Операції |
| --- | --- |
| `/api/organizers` | GET список, POST створення; `/{id}` GET, PUT, DELETE |
| `/api/venues` | GET список, POST створення; `/{id}` GET, PUT, DELETE |
| `/api/events` | GET список із `skip`, `limit`, `nextLink`; POST створення; `/{id}` GET, PUT, DELETE |

Для JSON події поле `startsAt` має містити часовий пояс, наприклад `2030-01-01T15:00:00Z`. Відповідь містить `startsAtUtc` із позначкою UTC. Максимальний `limit` становить 100. Кеш списку подій живе до 30 секунд і скидається після змін; заголовок `X-Cache` показує `HIT` або `MISS`.

Для браузерних тестів потрібні Node.js 24 та Microsoft Edge на Windows або Playwright Chromium на іншій платформі:

```powershell
npm ci
npm run test:e2e
```

Для тестів на вже запущеному локальному сервері:

```powershell
pwsh -NoProfile -File tests/Smoke.ps1
pwsh -NoProfile -File tests/ApiSmoke.ps1
npx --yes newman@6.2.2 run tests/postman/MistoPodii.postman_collection.json
```

Результати й межі покриття описані у [документі тестування](docs/TESTING.md). Методика порівняння SignalR транспортів і фактичні виміри є у [документі зв'язку](docs/CONNECTIVITY.md).

## Контейнер

`docker compose up --build` збирає образ і запускає застосунок на `http://localhost:8080`; база лежить у названому томі. Конфігурацію Compose перевірено, але реальний запуск контейнера на цій машині не підтверджено через недоступний Docker daemon.

## Безпека та публікація

Редакторські сторінки й операції запису API поки не мають автентифікації. Цю версію можна запускати локально для захисту роботи; відкривати її для публічного запису не можна. Публічне хмарне розгортання та автоматичне розгортання з `main` не заявляються виконаними. У GitHub Actions налаштовано збірку й браузерні тести, без удаваного кроку deployment.

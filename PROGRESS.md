# Журнал виконання

## 2026-09-24

- Прочитано повний перелік завдань курсу та обрано «Місто подій».
- Етап 1: три пов'язані сутності, EF Core SQLite migrations, демонстраційні записи та Razor CRUD. `dotnet build MistoPodii.sln --no-restore` завершився без попереджень; `tests/Smoke.ps1` пройшов.
- Етап 2: JSON CRUD, пагінація `skip/limit/nextLink`, кеш зі скиданням після змін. `tests/ApiSmoke.ps1` пройшов; Newman виконав 11 запитів і 12 перевірок без помилок.
- Етап 3: окрема сторінка події з постійним контактом, технічні SEO-метадані, `robots.txt`, `sitemap.xml` і autocomplete. Вибір місця перевірено в браузері. Зовнішній SEO-аудит ще не виконувався, бо немає публічної адреси.
- Етап 4: мапа OpenStreetMap із фільтрами, діаграма Chart.js і Open-Meteo. Фільтр змінював 2 точки на 1, список і діаграму; живий прогноз для події показав 9.1–17.2 °C і 10% опадів на 01.10.2026.
- Етап 5: SignalR надсилає зміну статусу без перезавантаження. У браузері статус змінився з «Заплановано» на «Перенесено» після API PUT. Виміряно WebSockets, Server Sent Events і Long Polling; сирі дані в `evidence/transport-benchmark-2026-09-24.json`.
- Етап 6: `npm run test:e2e` пройшов, 3 із 3 сценаріїв. `docker compose config --quiet` пройшов. Реальний Docker запуск не підтверджено: daemon недоступний, системна служба зупинена, запуск відхилено. Конфігурацію CI створено, але віддалений запуск ще не перевірено.
- Хмарне розгортання, CD, OAuth та зовнішній SEO-аудит не заявляються виконаними. Публічний запис до застосунку без автентифікації небезпечний; хмарний деплой чекає етапу 7.

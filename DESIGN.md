# Дизайн «Місто подій»

Аудиторія: людина, яка шукає конкретну локальну подію цього тижня. Головне завдання каталогу: швидко звузити список і відкрити інформацію про одну подію.

## Токени

| Роль | Значення |
| --- | --- |
| Тло сторінки | `#F2F6F5` |
| Основний текст | `#122D34` |
| Акцент маршруту | `#006E68` |
| Тепла позначка дати | `#E69B45` |
| Поверхня | `#FFFFFF` |
| Допоміжний текст | `#50666B` |

Заголовки: `Trebuchet MS`, із системним sans-serif fallback. Основний текст: `Segoe UI`, із системним sans-serif fallback. Дані часу і координат: `Consolas`, із monospace fallback. Контраст і видимий фокус перевіряються на реальних екранах.

## Композиція

Шапка нагадує навігаційну табличку, каталог подій виглядає як стрічка з датами, а не як сітка однакових карток. Одна вертикальна лінія з маркерами дат зв'язує записи й передає ідею міського маршруту. Подія відкривається в окремій сторінці з великою назвою, основною інформацією й постійно доступним контактом організатора. На вузькому екрані стрічка стає одноколонковою.

Ескіз каталогу:

```text
МІСТО ПОДІЙ                       Події  Місця  Організатори
Знайдіть, куди піти цього тижня
[пошук] [категорія] [дата]
│ 14 жовтня  Назва події              місце →
│ 16 жовтня  Назва події              місце →
```

Анімація не є необхідною для виконання завдання. Всі інтерактивні елементи доступні з клавіатури; режим зменшеного руху поважає налаштування браузера.

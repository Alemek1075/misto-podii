# Перевірка та покриття сценаріїв

Автоматизація перевіряє поведінку на рівні браузера й HTTP. Це покриття сценаріїв, а не відсоток виконаних рядків коду.

| Критичний сценарій | Доказ |
| --- | --- |
| Каталог → сторінка події → контакт і SEO | Playwright `catalog, event page, and SEO endpoints` |
| Фільтр мапи → точки, графік і список | Playwright `map filter changes points, chart summary, and event list` |
| MVC CRUD трьох сутностей, autocomplete, зміна статусу у двох вкладках | Playwright `MVC CRUD, autocomplete, and live status update` |
| MVC валідація основних форм і захист пов'язаного видалення | `tests/Smoke.ps1` |
| JSON CRUD, статуси, UTC, межі пагінації та інвалідація кешу | `tests/ApiSmoke.ps1` |
| Послідовність JSON API для демонстрації в Postman | `tests/postman/MistoPodii.postman_collection.json` через Newman |

Останній локальний запуск Playwright 24.09.2026: 3 із 3 сценаріїв пройшли. Останній запуск PowerShell smoke: обидва сценарії пройшли. Останній запуск Newman: 11 запитів, 12 перевірок, 0 помилок. Динаміку статусу додатково перевірено у відкритому браузері після PUT на `/api/events/1` без перезавантаження сторінки.

Не покрито автоматично: недоступність Open-Meteo, поведінку при втраті мережі, великі набори даних, підключення багатьох одночасних клієнтів і реальне хмарне розгортання. Зовнішній SEO-аудит потребує публічної адреси. Docker Compose пройшов лише синтаксичну перевірку, тому контейнерне розгортання ще не підтверджене.

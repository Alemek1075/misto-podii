# Короткий опис проєкту

«Місто подій» об'єднує навчальні завдання курсу Web-технології в один демонстраційний застосунок. Відвідувач читає афішу, фільтрує події на мапі, бачить окрему сторінку кожної події та актуальний прогноз на її дату. Редактор керує організаторами, місцями й подіями через MVC форми або JSON API. Зміна статусу події відображається в іншому браузері через SignalR.

Технології: .NET 8, ASP.NET Core MVC, EF Core SQLite, Razor, Bootstrap, jQuery, Leaflet, Chart.js, OpenStreetMap tiles, Open-Meteo, SignalR, Playwright і Newman. Усі потрібні JS/CSS бібліотеки для роботи сторінок лежать у `wwwroot/lib`; зовнішні мережеві запити використовують лише мапові тайли й погодний API.

Основні файли: `SPEC.md` фіксує вимоги та модель; `PROMPTS.md` містить послідовні етапи до п'яти годин; `DESIGN.md` описує UI; `README.md` містить запуск; `PROGRESS.md` містить фактичний стан. Код застосунку в `src/MistoPodii`, перевірки в `tests`, сирі виміри в `evidence`.

Поточний стан: MVC CRUD, API, пагінація, кеш, лендінг, технічне SEO, autocomplete, мапа, графік, прогноз, SignalR і E2E реалізовані та локально перевірені. Контейнер і CI описані кодом, але контейнер не вдалося запустити через недоступний Docker daemon; CI у віддаленому репозиторії ще не спрацьовував. Хмарне розгортання, CD та зовнішній SEO-аудит ще не підтверджені. Наявні редакторські маршрути публічно не захищені: перед хмарним розгортанням потрібна автентифікація й авторизація.

Для відтворення: `dotnet restore`, `dotnet run --project src/MistoPodii`, потім відкрити показану URL. Для автоматичних тестів: `npm ci` та `npm run test:e2e`. Актуальні точні результати у `PROGRESS.md`.
